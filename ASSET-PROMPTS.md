# MIRA image generation record

The visual concept and all six raster assets in `src/EcommerceApi.Web/public/images` were created with the built-in Image Gen tool. They are original generated visuals, not copied from the Evara package. The concept image is included separately in the handoff outputs.

## Concept

> Use case: ui-mockup. Create a complete, highly legible desktop screenshot concept for an original reusable fashion ecommerce storefront template called 'MIRA'. It is to be implemented in React and Bootstrap 5, connected to an existing API. 1440px wide desktop layout. Visual style: premium contemporary editorial retail, off-white background #f8f7f4, charcoal text, deep olive accent #4b5744, restrained typography, elegant serif display headings and clean sans UI. Header with wordmark MIRA at left, links Shop, New arrivals, Journal, search icon, account icon, cart icon. Main hero takes first viewport: left aligned text 'Considered pieces for everyday living', short subcopy, button 'Shop the collection'; right half full-height high-quality editorial photo of neutral contemporary apparel on a model. Below: a slim service bar, 'New arrivals' heading with 4 product cards and genuine photographed garments, then a wide collection campaign and footer. All interface text and buttons must be legible and easy to implement as code-native controls. No badges or pills above hero heading. Use one cohesive design system, ample whitespace, real content, professional catalog photography, no copied Evara branding or layouts. Avoid excessive cards, gradients, fake metrics, unrelated sections. This is design concept only, not an image to ship as the UI.
